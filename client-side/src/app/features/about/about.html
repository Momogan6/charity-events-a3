About the platform

Charity Events is a complete dynamic website built for PROG2002 Web Development II (Assessment 3). The client website you are reading and the separate admin website are both Angular 22 single-page applications that read and write all of their data through a RESTful API backed by MySQL.

🏗 Architecture
  1. Angular 22 client website — this site. Standalone components, signals, reactive forms, routing.
  2. Angular 22 admin website — a separate application for staff to manage events.
  3. Node.js + Express REST API — the only component that talks to the database.
  4. MySQL database — charityevents_db, with three related tables and views.
  5. Open-Meteo Weather API — external data, proxied through our own endpoint.

👥 How registration works

A visitor searches for an event, opens its detail page, and clicks Register for this event. The registration page collects their details and sends them to POST /api/registrations. The API validates every field, checks the event is still active and that enough seats remain, then inserts the row. The UNIQUE (event_id, email) index guarantees nobody can register twice for the same event, and a database trigger stops the event from being over-booked.
