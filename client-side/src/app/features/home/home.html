💡 How the platform works
  1. Search or browse the charity events listed on this site.
  2. Open an event to see its details and everyone who has already registered.
  3. Choose how many tickets you need and complete the registration form.
  4. Your booking is stored in our MySQL database through our REST API.

This website is a dynamic single-page application: every list, detail view and confirmation you see is fetched from the Charity Events REST API — no page content is hard-coded in the HTML.
